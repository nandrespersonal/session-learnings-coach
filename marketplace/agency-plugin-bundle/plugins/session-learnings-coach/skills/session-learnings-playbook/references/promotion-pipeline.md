# Promotion pipeline

Learnings should not all become rules.

Use this pipeline:

1. `captured`: lesson recorded for future review
2. `candidate-rule`: lesson has repeated or has high enough cost to deserve a rule
3. `promoted-personal-rule`: added to personal operating instructions
4. `promoted-team-guidance`: converted into team guidance or documentation
5. `archived`: superseded, stale, or merged into a stronger learning

Promotion should be deliberate. A rule is useful only if it changes future behavior.
