# Marketplace positioning

## Name

Session Learnings Coach

## Short description

Turn AI-assisted work sessions into reusable lessons, better prompts, and team-ready operating principles.

## Description

Session Learnings Coach helps individuals and teams run lightweight retrospectives after AI-assisted work. It captures what worked, what failed, what prompt would have helped, and what should change next time.

The plugin separates one-off mistakes from repeated patterns, classifies privacy before sharing, and helps promote important lessons into personal rules or team guidance.

This is an early productivity plugin, not a memory platform or telemetry collector. Feedback is welcome, especially on additional learning types, privacy levels, export formats, and promotion workflows.
